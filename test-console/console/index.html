what leaves, and what stays

Everything runs on this PC: the real Presidio scanner in Docker, and the gateway and paywall built from main. By default the "model" is a stand-in that echoes what it received, so no real model is called and nothing leaves this computer. After use-real-models.cmd, chat goes to OpenRouter's free models, and they receive only the masked text. The paywall runs on TestNet, and no payment is made.

Decision ledger

The gateway writes one line per request, recording what kind of data was found and which model answered. It must hold no text, no placeholders and no map.

If Presidio cannot be reached, scan, mask and chat all answer 503 and /healthz reports 503. Text that has not been scanned is never forwarded anywhere — that is the one rule the rest of the design is built around.
